# Rust Roguelike Generator - WIP
### Создание roguelike данжей для карт Rust.

Генератор берёт шаблоны комнат (`maps/map_room*.map`), раскладывает их на сетке в связный данж и кладёт результат поверх `maps/_base.map` в `finalresult.map`.

- Все комнаты связаны между собой (остовное дерево + немного петель).
- Комната с дверным проёмом поворачивается дверью к комнате, из которой в неё пришли.
- На сторонах с проходом стены убираются, дверные проёмы сохраняются.
- Один и тот же seed всегда даёт один и тот же данж.

## Запуск

```
dotnet run --project RoguelikeGenerator                 # интерактивно
dotnet run --project RoguelikeGenerator -- 10 25 1337   # сетка 10x10, 25 комнат, seed 1337
dotnet run --project RoguelikeGenerator -- --info maps/map_room_ext.map   # разбор шаблона
```

Если в `maps/` нет `_base.map` или шаблонов комнат, они скачиваются из репозитория.

## Свои комнаты

Отредактируйте `maps/map_cleared.map` в RustEdit и сохраните как `maps/map_room_<имя>.map`.

- Пол: самый большой по площади префаб, его центр считается центром комнаты, а размер задаёт шаг сетки.
- Стены: префабы у края комнаты (ближе 0.5 м), на сторонах с проходом они убираются.
- Дверь: сторона, стены которой у пола закрывают не всю ширину. Такая сторона должна быть одна.

Проверить, как генератор понял шаблон: `--info maps/map_room_<имя>.map`.
